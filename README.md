## 📊 Work Sample / Project Description  
For this artifact, I created an **AI Insights Dashboard** in **Power BI** that visualizes key machine-learning results—prediction accuracy, engagement patterns, and performance trends.  
The goal was to make complex AI outputs understandable for non-technical audiences and show how visualization bridges technical analysis and business strategy.  

I collected and cleaned model-output data in **Excel**, built dynamic visuals in **Power BI**, and used **DAX formulas** to calculate growth and accuracy metrics.  
To improve readability, I applied color theory and accessibility design and refined the dashboard layout based on instructor and peer feedback.
